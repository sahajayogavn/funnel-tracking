# Use cases

**Universal ID:** `doc:readme-usecases-001`

Tài liệu use case theo góc nhìn người dùng của Funnel Tracking nằm tại
[seeker-care-operations.md](seeker-care-operations.md).

Tài liệu này mô tả những gì đội chăm sóc seeker, người duyệt và điều phối viên
có thể làm với hệ thống; không thay thế tài liệu kiến trúc hoặc hướng dẫn vận
hành CLI. Mỗi use case nêu rõ ranh giới tự động hóa và các bước vẫn cần con
người thực hiện.
