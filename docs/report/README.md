# Audit reports

**Universal ID:** `doc:readme-audit-reports-001`

Thư mục này lưu các báo cáo audit theo từng phạm vi: stage gates, warm-up, event, QA và quyết định kiến trúc. Chúng là bản ghi theo thời điểm; không nên coi các kết luận runtime trong đó là trạng thái hiện hành nếu chưa đối chiếu với mã nguồn.

Xem thêm các báo cáo QA và retrospective độc lập tại [`../reports/`](../reports/).
